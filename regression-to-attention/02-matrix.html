Von der Geraden zur Attention · Kapitel 2 von 9

Die Matrix

Was eine Matrixmultiplikation mit Daten macht: drehen, spiegeln, strecken, scheren, plattdrücken, und in welchem Raum die Daten danach landen.

Die neue Idee

Eine Matrix verformt den ganzen Raum auf einmal. Wohin die Einheitspfeile gehen, bestimmt, wohin jeder andere Punkt geht.

1Zwei Pfeile bestimmen alles

Eine 2×2-Matrix nimmt jeden Punkt der Ebene und schickt ihn woandershin. Welche Verformung sie ist, sieht man an ihren beiden Spalten.

Dahinter steckt

Spalte 1 ist das Ziel von (1, 0), Spalte 2 das Ziel von (0, 1). Jeder andere Punkt ist eine Mischung aus beiden, und genau so wird er abgebildet:

Mx = x1 · Spalte 1 + x2 · Spalte 2

Deshalb bleiben Gitterlinien gerade, parallel und gleichmäßig verteilt, und der Ursprung bleibt, wo er ist. Die Determinante sagt, um wie viel sich Flächen ändern; ist sie negativ, ist die Ebene gespiegelt, ist sie null, wird eine Richtung ganz plattgedrückt.

2Drehen, strecken, drehen

Egal wie verdreht eine Matrix aussieht: Sie lässt sich immer in drei einfache Schritte zerlegen. Das hier ist die Matrix von oben, zerlegt.

Dahinter steckt

Das ist die Singulärwertzerlegung M = U Σ V⊤. Aus dem Kreis wird eine Ellipse; ihre Halbachsen σ1 und σ2 sind die stärkste und die schwächste Streckung, die die Matrix überhaupt kann. Ist σ2 = 0, geht eine Richtung ganz verloren. Diese Zerlegung begegnet uns wieder, wenn wir in Kapitel 9 die Gewichte eines Transformers lesen.

3Hintereinander ausführen

Das Produkt zweier Matrizen ist die Verformung, die beide nacheinander ausführt. Das ist die eigentliche Bedeutung der Matrixmultiplikation.

Dahinter steckt

ABx liest man von rechts: erst B, dann A. Meist zählt die Reihenfolge. Und egal wie viele Matrizen man hintereinanderschaltet, heraus kommt wieder eine einzige Matrix. Ein Netz aus lauter Matrizen wäre also nicht mächtiger als eine Schicht. Das ändert erst eine Nichtlinearität dazwischen, in Kapitel 4.

4Hinauf in den Raum

Eine Matrix muss nicht quadratisch sein. Eine 3×2-Matrix nimmt einen Punkt der Ebene und macht daraus einen Punkt im Raum.

Dahinter steckt

Das Ergebnis hat drei Koordinaten, füllt aber nur eine Ebene: den Spaltenraum, aufgespannt von den beiden Spalten. Mehr Freiheitsgrade als Eingaben kann eine Matrix nicht erzeugen. Die Vorlage „X aus Kapitel 1“ ist genau die Ebene aller Vorhersagen aus Kapitel 1: Jeder Punkt (w, b) der Eingabe ist eine Gerade, sein Bild sind ihre drei Vorhersagen.

5Hinunter in die Ebene

Eine 2×3-Matrix macht das Umgekehrte: Sie wirft den Raum auf eine Ebene. Jedes Foto ist so eine Matrix.

Dahinter steckt

Jede Zeile der Matrix liest eine Koordinate ab: ein Skalarprodukt, also wie weit der Punkt in Richtung dieser Zeile liegt. Eine Richtung bleibt dabei ungelesen, der Kern. Alle Punkte auf einer Linie entlang des Kerns fallen auf denselben Bildpunkt; von oben wird die Spirale zum Kreis, die Höhe ist weg. Welche Richtungen man beim Plattdrücken behalten sollte, ist eine Leitfrage für Kapitel 5.

6Zeile mal Spalte

Zurück zu den Wohnungen aus Kapitel 1. Die Matrix X hat eine Zeile pro Wohnung: (Fläche, 1). Mal θ = (w, b) ergibt sie alle 14 Vorhersagen auf einmal.

Dahinter steckt

Jeder Eintrag des Ergebnisses ist ein Skalarprodukt: eine Zeile mal θ. Die Formate verketten sich: (14 × 2) · (2 × 1) = (14 × 1). Dasselbe Muster kommt in der Attention wieder, als (n × d) · (d × n): jedes Wort mit jedem.

7Was eine Matrix nicht kann

Drehen, spiegeln, strecken, projizieren: alles, was eine Matrix tut, hält Geraden gerade und den Ursprung an seinem Platz. Biegen oder falten kann sie nicht. Um zwei ineinander verschlungene Datenwolken zu trennen, braucht man genau das. Kapitel 3 zeigt zuerst, wie man mit einer einzigen Grenze klassifiziert; Kapitel 4 faltet dann den Raum.
