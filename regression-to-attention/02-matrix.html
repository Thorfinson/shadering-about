Grundlage

Punkte sind Pfeile

Ein Punkt mit zwei Zahlen ist ein Pfeil vom Ursprung aus: so weit nach rechts, so weit nach oben. Anders gesagt: eine Mischung aus zwei Einheitspfeilen.

So ein Pfeil heißt Vektor. Jede Wohnung aus Kapitel 1, jedes Pixel, jedes Wort in einem Sprachmodell ist so ein Vektor, nur oft mit viel mehr Zahlen.

Die Idee

Eine Matrix verschiebt die Einheitspfeile

Eine Matrix ist eine Anweisung: Schicke den rechten Einheitspfeil hierhin, den oberen dorthin. Diese beiden Ziele sind ihre Spalten.

Alles andere folgt von selbst: Gitterlinien bleiben gerade und parallel, der Ursprung bleibt fest. Die ganze Ebene verformt sich auf einmal.

Formel lesen

Wohin geht ein Punkt?

Ein Punkt war eine Mischung der Einheitspfeile. Nach der Matrix ist er dieselbe Mischung der Spalten. Mehr steckt in M·x nicht.

Formel lesen, andersherum

Zeile mal Vektor

Man kann dasselbe auch zeilenweise rechnen: Jede Zeile der Matrix liefert eine Koordinate des Ergebnisses, als Skalarprodukt: Einträge multiplizieren, aufsummieren.

Das ist genau die Rechnung w · x + b aus Kapitel 1. Jede Zeile ist ein Neuron; die Matrix ist viele Neuronen nebeneinander.

Einfachster Fall

Strecken

Stehen nur auf der Diagonalen Zahlen, wird jede Achse für sich gestreckt oder gestaucht. Aus dem Kreis wird eine Ellipse, aus dem Quadrat ein Rechteck.

Die Determinante sagt, um welchen Faktor sich Flächen ändern.

Kennen wir schonDas Standardisieren aus Kapitel 1 ist so eine Streckung: Die Fläche wird durch s geteilt. Auch jeder Zoom und jede Umrechnung von Einheiten ist eine.
Negativer Faktor

Spiegeln

Streckt man eine Achse mit einem negativen Faktor, klappt die Ebene um. Das F schaut danach in die andere Richtung, und die Determinante wird negativ.

Anderes BeispielEin linker und ein rechter Handschuh: Keine Drehung macht aus dem einen den anderen, nur eine Spiegelung.
Starr bewegen

Drehen

Bei einer Drehung bleiben alle Längen und Winkel erhalten. Die Spalten sind zwei senkrechte Pfeile der Länge 1, deshalb stehen dort Kosinus und Sinus.

Anderes BeispielWenn du auf dem Handy ein Foto drehst, wird jede Pixelposition mit genau so einer Matrix multipliziert.
Schieben

Scheren

Bei einer Scherung wird jede Zeile umso weiter zur Seite geschoben, je höher sie liegt. Die Fläche bleibt gleich, aber rechte Winkel verschwinden.

Anderes BeispielKursivschrift ist fast genau eine Scherung der normalen Schrift.
Information geht verloren

Plattdrücken

Zeigen beide Spalten in dieselbe Richtung, fällt die ganze Ebene auf eine Gerade, das Bild. Eine Richtung, der Kern, wird ganz zu null gequetscht. Die Determinante ist null, und man kann nicht mehr zurückrechnen.

Anderes BeispielEin Schatten an der Wand: Aus dem Schatten allein weiß man nicht mehr, wie tief das Objekt war.
Matrizen multiplizieren

Hintereinander ausführen

Das Produkt zweier Matrizen ist die Verformung, die beide nacheinander ausführt. AB liest man von rechts: erst B, dann A.

Die Reihenfolge zählt: Erst strecken, dann drehen ergibt etwas anderes als erst drehen, dann strecken.

Folge davon

Viele Schichten sind eine Matrix

Egal wie viele Matrizen man hintereinanderschaltet: Heraus kommt wieder genau eine Matrix. Ein Netz aus lauter Matrizen wäre also nicht mächtiger als eine einzige Schicht.

Das ändert erst eine Nichtlinearität dazwischen, in Kapitel 4.

Alles zusammen

Drehen, strecken, drehen

Jetzt sieht man, dass die einfachen Fälle reichen: Jede Matrix lässt sich in drei Schritte zerlegen. Erst drehen, dann entlang der Achsen strecken, dann noch einmal drehen.

Das heißt Singulärwertzerlegung. Die Streckfaktoren σ sagen, in welcher Richtung die Matrix am stärksten und am schwächsten wirkt; wir brauchen sie wieder, wenn wir in Kapitel 9 ein Netz lesen.

Andere Räume

Von zwei auf drei Dimensionen

Eine Matrix muss nicht quadratisch sein. Mit drei Zeilen und zwei Spalten macht sie aus jedem Punkt der Ebene einen Punkt im Raum.

Aber die Bilder füllen nicht den Raum: Sie liegen alle auf einer Ebene, aufgespannt von den beiden Spalten. Dieser Spaltenraum ist alles, was die Matrix erreichen kann.

Andere Räume

Von drei auf zwei Dimensionen

Mit zwei Zeilen und drei Spalten geht es umgekehrt: Der Raum wird auf eine Ebene geworfen, wie bei einem Foto. Jede Zeile liest eine Bildkoordinate ab.

Eine Richtung bleibt ungelesen, der Kern. Von oben fotografiert wird die Spirale zum Kreis; die Höhe ist weg.

Anderes BeispielEin Farbfoto in Graustufen umrechnen ist sogar eine 1×3-Matrix: Grau = 0,30·Rot + 0,59·Grün + 0,11·Blau.

Die Regression ist eine Matrix

Schreibt man die 14 Wohnungen untereinander, Zeile für Zeile (Fläche, 1), entsteht eine Matrix X. Mal den Parametern θ = (w, b) liefert sie alle 14 Vorhersagen auf einmal: Zeile mal Vektor, 14-mal.

Die beste Gerade ist ein Lot

X hat zwei Spalten, also ist ihr Spaltenraum eine Ebene: alle Vorhersagen, die irgendeine Gerade machen kann. Mit drei Wohnungen sehen wir sie im Raum.

Die echten Mieten y liegen fast nie in dieser Ebene. Die beste Gerade ist der Punkt der Ebene, der y am nächsten liegt, der Fußpunkt des Lots. Deshalb steht der Fehler immer senkrecht auf der Ebene.

Die runde Schüssel, erklärtZentriert man die Flächen, stehen die beiden Spalten von X senkrecht aufeinander. Dann stören sich w und b nicht mehr, und genau deshalb wurde die Schüssel in Kapitel 1 rund.
Ausblick

Was eine Matrix nicht kann

Blaue Punkte innen, orange Punkte im Ring drumherum. Keine Matrix bekommt die inneren aus dem Ring heraus: Geraden bleiben gerade, der Ursprung bleibt, innen bleibt innen.

Um solche Daten zu trennen, muss man den Raum biegen und falten. Das ist die Idee der neuronalen Netze, Kapitel 4.
